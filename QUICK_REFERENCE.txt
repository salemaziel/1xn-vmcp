AUTH ENDPOINTS (All /api):
─────────────────────────
POST   /register           → Create user
POST   /login              → Username/password auth
POST   /refresh            → Get new access token
POST   /logout             → Revoke session
GET    /userinfo           → Get current user
POST   /auth/ws-ticket     → Get WebSocket ticket

TOKENS:
───────
Access:  15 min  (localStorage)
Refresh: 7 days  (HttpOnly cookie)
WS:      30 sec  (query param)

All signed with HS256

PASSWORD HASHING:
─────────────────
Scrypt(n=2^14, r=8, p=1) → Base64
Format: scrypt${n}${r}${p}${salt}${digest}

SESSION REVOCATION:
──────────────────
Method: session_nonce in JWT + database
On logout: Rotate nonce → all tokens invalid
No token blacklist needed

ENVIRONMENT VARIABLES:
──────────────────────
Required:
  VMCP_JWT_SECRET_KEY=<secret>

Optional:
  VMCP_JWT_ALGORITHM=HS256
  VMCP_ACCESS_TOKEN_TTL_SECONDS=900
  VMCP_REFRESH_TOKEN_TTL_SECONDS=604800
  VMCP_WEBSOCKET_TICKET_TTL_SECONDS=30
  VMCP_AUTH_COOKIE_SECURE=false
  VMCP_AUTH_COOKIE_DOMAIN=
  VMCP_ALLOW_SELF_REGISTRATION=true
  VMCP_TRUSTED_PROXIES=127.0.0.1
  VMCP_ALLOWED_HOSTS=localhost,127.0.0.1

FOR STAGE 2 (OAUTH):
────────────────────
See: STAGE2_AUTH_IMPLEMENTATION_GUIDE.md

DO REUSE:
  • LocalJWTService (extend for OAuth)
  • TokenInfo dataclass
  • Cookie management functions
  • MCP middleware

DON'T CONFUSE:
  • oauth_handler.py (MCP server OAuth) ≠ User OAuth
  • Create NEW: backend/src/vmcp/server/oauth_service.py

WATCH OUT FOR:
  • User ID linking (local vs provider)
  • Email conflicts (same email, local + OAuth)
  • Logout revocation (both vMCP + provider)
  • Token refresh rotation
